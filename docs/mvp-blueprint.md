# MVP 蓝图

这份蓝图是一期原型的简版总览，详细规划见 [docs/phase-1-prd.md](/Users/yuyu/Desktop/Bosch/docs/phase-1-prd.md)。

## 一期定位

- 试点工厂：博世杭州电动工具工厂
- 试点产线：电钻产线
- 一期目标：以管理层视角为主，围绕 OEE 提升建立设备全生命周期管理驾驶舱
- 原型形态：建设可演示的可视化原型，允许首期数据不完整

## 一期核心范围

### 1. 设备生命周期管理

- 生命周期统一口径：`引入 / 安装 / 量产 / 维护 / 升级 / 退役`
- 展示设备在不同阶段的分布和状态
- 支持识别升级与退役窗口

### 2. OEE 与运营效率

- 展示设备级与产线级 OEE
- 展示稼动率、停机时长和主要损失点
- 为管理层识别低效设备和重点改善对象

### 3. 资料与布局完备性

- 图纸版本是否完整
- Layout 是否与工位/产线布局一致
- 设备、工位、图纸和 layout 的绑定关系

### 4. 备件保障风险

- 关键备件库存
- 安全库存阈值
- 交期与缺件风险

## 风险表达方式

一期采用规则自动判定，构建红黄绿风险识别：

- 红色：OEE 严重偏低、异常停机频发、关键备件低于安全库存、图纸或 layout 缺失且影响运行
- 黄色：OEE 波动、临近保养、资料待确认、备件接近安全库存
- 绿色：运行稳定、资料完整、库存正常

## 页面结构

### 首页管理驾驶舱

- 顶部 KPI
- 生命周期分布
- 关键设备看板
- 风险总览与 TOP 问题设备
- 关键备件风险
- 实施路径与数据整合提示

### 二级下钻

- 设备明细
- 异常原因摘要
- 维护与保养记录
- 图纸/layout 状态
- 关键备件保障情况

## 数据范围

一期建议统一以下五类数据：

- 设备主数据
- 效率数据
- 维护数据
- 备件数据
- 图纸/layout 数据

## 实施节奏

### 阶段 1：原型与口径对齐

- 固化试点范围
- 确认首页结构
- 确认红黄绿规则
- 确认字段清单

### 阶段 2：单线数据接入

- 汇总设备台账
- 汇总 OEE 与停机数据
- 汇总保养记录
- 汇总备件与图纸/layout 清单

### 阶段 3：原因下钻

- 支持从管理驾驶舱进入设备明细
- 支持展示异常原因与缺失项

### 阶段 4：扩展复制

- 扩到更多设备类型
- 扩到更多产线
- 评估后续 Agent 场景
