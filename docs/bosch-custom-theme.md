# Bosch Factory Pulse

这是基于 `theme-factory` 思路，为当前 Bosch 电动工具原型汇报定制的一套主题。

## Color Palette

- **Bosch Red**: `#E20015`
  主要强调色，用在标题强调、重点标签、关键动作。
- **Bosch Blue**: `#005691`
  次强调色，用在辅助按钮、次级标签、流程连接和数据卡片。
- **Factory White**: `#FFFFFF`
  主背景色，保证内容清晰、截图干净。
- **Soft Surface**: `#F3F3F3`
  次背景，用在页面分区和弱对比内容区。
- **Text Dark**: `#1A1C1C`
  正文主色。
- **Muted Gray**: `#5B6370`
  说明文字、页脚、小标签。
- **Soft Red Tint**: `#FFEBE9`
  轻提示、说明、风险提醒底色。
- **Soft Blue Tint**: `#E8F2FB`
  结构说明、辅助模块底色。

## Typography

- **Headers**: Microsoft YaHei Bold
- **Body**: Microsoft YaHei

## Visual Direction

- 整体风格偏“工厂运营看板”，不是花哨的市场宣传稿。
- 页面尽量留白，突出截图本身。
- 重复使用红色顶条、圆角卡片、红蓝双色标签，形成统一识别。
- 让截图成为主角，文字只负责带节奏，不堆太多说明。

## Slide Style Rules

- 标题页尽量大图 + 短句。
- 内容页优先使用 2 栏或 3 栏，不做满页堆字。
- 每页最多只讲一个核心点。
- 说明类页面用自然一点的口吻，避免过于正式的 PRD 语气。
