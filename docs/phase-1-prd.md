# 博世杭州电动工具工厂设备周期管理可视化平台

## 一期 PRD / 规划文档

### 1. 文档信息

- 文档状态：Draft v1
- 日期：2026-04-24
- 试点工厂：博世杭州电动工具工厂
- 试点产线：电钻产线
- 业务重点：总装设备、测试设备
- 一期主目标：以管理层视角为主，围绕 OEE 提升搭建设备全生命周期管理驾驶舱

### 2. 项目背景

当前设备管理相关信息分散在不同对象和流程里，例如设备台账、维护记录、备件库存、图纸资料、layout 变更和生产效率数据。管理动作往往依赖经验判断，缺少统一、可下钻、可持续复用的数据视图。

在博世杭州电动工具工厂的电钻产线场景下，一期项目旨在将设备从引入到退役的核心信息统一纳入同一张管理画布，帮助管理层快速识别：

- 设备资产结构是否健康
- OEE 低点集中在哪些设备和工位
- 图纸与 layout 是否支撑现场稳定运行
- 关键备件是否存在停线风险

### 3. 一期目标

#### 3.1 业务目标

- 建立一个可演示、可复盘、可扩展的管理驾驶舱原型
- 让管理层能够快速定位影响 OEE 的关键设备和风险主题
- 为设备、维修、生产、备件等角色建立统一口径
- 为后续跨系统数据整合打基础

#### 3.2 一期不追求的目标

- 不在一期做完整的多工厂对比
- 不在一期做深度工单流程系统
- 不在一期把 Agent 作为核心交付物
- 不在一期追求全量系统全自动打通

### 4. 试点范围

#### 4.1 组织范围

- 工厂：博世杭州电动工具工厂
- 产线：电钻产线
- 设备类型：总装设备、测试设备

#### 4.2 用户角色

- 工厂管理层
- 设备经理 / 设备工程师
- 维修 / 保养团队
- 生产经理 / 产线负责人
- 备件 / 仓储 / 采购

#### 4.3 使用场景

- 管理层周会 / 月会查看产线设备状态
- 设备团队查看关键异常设备和资料缺失项
- 生产团队查看 OEE 低点与停机风险
- 备件团队识别关键低库存物料

### 5. 生命周期口径

一期统一采用通用六阶段定义，后续可映射内部口径：

| 阶段 | 定义 | 管理关注点 |
|---|---|---|
| 引入 | 设备选型、预算、方案准备 | 设备导入节奏、资料准备情况 |
| 安装 | 设备安装、调试、layout 校核 | 交付进度、上线准备度 |
| 量产 | 稳定生产与效率兑现 | OEE、停机、节拍、质量影响 |
| 维护 | 保养与异常修复 | PM 执行、故障频次、MTBF / MTTR |
| 升级 | 改造、能力提升、节拍优化 | 投入收益、实施进度、风险窗口 |
| 退役 | 替换、淘汰、退出运行 | 保留 / 升级 / 替换决策 |

### 6. 管理驾驶舱设计原则

- 以结果视图为主：首页优先给管理层看结论
- 支持原因下钻：从总览进入设备明细，查看异常来源
- 风险自动判定：一期使用规则引擎而不是人工逐台标注
- 资料与 layout 不做附件管理，而是与工位/产线强绑定
- 接受一期数据不完整，但必须统一设备、工位、产线主键口径

### 7. 一期 MVP 功能范围

#### 7.1 首页管理驾驶舱

展示以下内容：

- 设备总数、量产设备数
- 平均 OEE、平均稼动率、总停机时长
- 生命周期分布
- 红黄绿风险总览
- TOP 问题设备
- 图纸 / layout 完备率
- 关键备件安全库存风险

#### 7.2 设备全景台账

每台设备至少展示：

- 设备编码、名称、设备类型
- 所属工厂、产线、工位
- 负责人
- 生命周期阶段
- OEE、稼动率、停机时长
- MTBF、MTTR
- 图纸状态、layout 状态
- 关键备件风险
- 下次保养时间

#### 7.3 风险专题

一期先拆成三类风险：

- 运行风险：低 OEE、异常停机、故障频发
- 资料风险：图纸缺失、版本不一致、layout 未更新
- 保障风险：关键备件低库存或交期长

#### 7.4 二级下钻

从管理首页进入单设备后，展示：

- 设备基础画像
- 当前主要风险命中项
- 近期开停机与故障摘要
- 保养计划与执行情况
- 图纸 / layout 绑定情况
- 关键备件状态

### 8. 首页信息架构

建议首页从上到下采用以下结构：

#### 8.1 顶部 KPI 区

- 设备总数
- 平均 OEE
- 平均稼动率
- 本周停机时长
- 红色风险设备数
- 资料 / 布局完备率

#### 8.2 生命周期分布区

- 六阶段数量分布
- 当前处于升级 / 退役窗口的设备数量

#### 8.3 OEE 提升主视图

- 关键设备卡片
- 低 OEE 设备排行
- 停机影响摘要

#### 8.4 风险总览区

- 红黄绿风险分布
- TOP 问题设备
- 问题原因标签

#### 8.5 资料与备件区

- 图纸非最新清单
- layout 待更新清单
- 关键备件低库存清单

### 9. 红黄绿规则自动判定

一期采用规则自动判定。建议初版从可解释规则开始，而不是复杂模型。

| 风险等级 | 建议规则 | 管理含义 |
|---|---|---|
| 红色 | OEE 低于阈值；近周期异常停机频繁；关键备件低于安全库存；图纸或 layout 缺失且影响运行 | 需要立即关注 |
| 黄色 | OEE 波动明显；临近保养；图纸或 layout 状态待确认；备件接近安全库存 | 需要跟踪 |
| 绿色 | OEE 稳定；保养正常；资料完整；库存正常 | 维持现状 |

建议一期由设备工程、维修、生产三方共同定义阈值，例如：

- OEE 红线阈值
- 停机时长阈值
- 连续异常次数阈值
- 备件低库存阈值
- 图纸 / layout 缺失判定逻辑

### 11. 数据现状假设与整合策略

当前对数据现状的判断是：不同主题数据大概率分散在不同系统或不同管理方式中，短期内需要接受半自动整合。

一期建议策略：

- 统一设备、产线、工位编码
- 使用字段映射表梳理不同来源
- 允许 Excel 作为过渡输入
- 先实现汇总可视，再逐步推进系统级打通

一期重点不是“数据百分百自动同步”，而是“先形成稳定口径和管理画布”。

### 12. 建议实施路径

#### 阶段 1：原型与口径确认

- 输出首页原型
- 确认风险规则
- 确认生命周期口径
- 确认首批字段表

#### 阶段 2：单线数据梳理

- 盘点设备主数据
- 获取 OEE / 停机数据
- 盘点保养与故障记录
- 盘点关键备件
- 盘点图纸与 layout

#### 阶段 3：单线试运行

- 用真实数据替换样例数据
- 运行管理驾驶舱
- 校正规则阈值
- 确认周会 / 月会使用方式

#### 阶段 4：复制与扩展

- 扩到更多设备类型
- 扩到更多产线
- 评估 Agent、预测分析等增强能力

### 13. 原型说明

当前仓库内已经提供一个零依赖静态原型，用于演示：

- 管理驾驶舱首页结构
- 生命周期分布
- 关键设备看板
- 红黄绿风险示意
- 关键备件和资料 / layout 风险
- 项目实施路线
